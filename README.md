Community content publishing tools, stat leaderboards and scouting pages for League of Legends amateur leagues and tournaments — live at **[leaguerankr.com](https://leaguerankr.com)**.

<img width="600" alt="image" src="https://github.com/user-attachments/assets/1dd5182c-b732-4453-b61b-da5c38f806c7" />

## Key Features
- **Team Power Rankings**: Rank teams weekly using a drag-and-drop editor with comments field and automatic rank change tracking. Shareable via PNG image export and links with rich OpenGraph support.
- **Consensus Power Rankings**: Automated community consensus cards average all published submissions with automatic rank change tracking. Shareable via PNG image export.
- **Player Tier Lists**: Rank players overall or by role using a drag-and-drop editor with comments field. Shareable via PNG image export and links with rich OpenGraph support.
- **Stats Dashboard & Scouting Suite**: Automatically generate customizable player stat leaderboards (including a bespoke, role-normalized Rankr player rating algorithm), season standings and playoff brackets, champion pick/ban numbers and other miscellaneous stats at a glance. Generate **Team**, **Player**, **Champion**, and **Match Series** scouting pages including champion draft breakdowns and per-player Solo/Duo history + champion mastery sync. Collect data by scanning a Google Sheets tab, manual database import, or automatically via Riot Tournament API codes.
- **Multi-League Operations & Match Hubs**: Per-league Operators, league/global creator allowlists, configurable season structures and schedules, CSV & Riot Match-V5 ingestion, and a Team Captain **Match Hub** combining upcoming schedules, opponent scouting, and Riot Tournament Code scaffolding.

## Additional Features
- **Community Blogs**: Write articles in a markdown-based editor with optional attachment to a specific league/season.
- **Private Champion Pool Builder**: Create and share your personal champion pools, with output stored locally and encrypted, complete with automatic champion/role population and matchup lookups.
- **Publishing Controls & Automatic Content Moderation**: Discord OAuth authentication, per-league and per-user content creation allow-listing, server-enforced content moderation rules and logging.
